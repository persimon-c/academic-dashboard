A terminal-based utility dashboard for tracking academic progress, schedules, sleep logs, grades, and organization commitments in real-time.

---

## What is SMON OS?

**SMON OS** is a highly structured, local Obsidian vault serving as a personal **Second Brain**. It acts as the central nervous system for:
- **Academics**: Course lecture logs, schedules, syllabus guides, exam dates, and grades.
- **Productivity**: Git commit metrics, todo tracking, and daily journals.
- **Organization**: Sprint timelines and event calendars for UPLB COSS (Computer Science Society).
- **Personal Health**: Daily sleep logs (wake-up times, bedtimes, and notes).

SMON OS operates on a **zero-overhead, read-only paradigm**—no data is generated by this dashboard. The Second Brain is the sole source of truth, and the dashboard reads existing signals to surface context.

---

## Tech Stack

The dashboard is built from scratch in **Rust** for maximum performance, minimal footprint, and thread safety:

- **UI Framework**: [ratatui](https://github.com/ratatui/ratatui) (v0.29) with [crossterm](https://github.com/crossterm-rs/crossterm) backend for raw terminal window rendering, custom layout configurations, and color handling.
- **Data Threading**: [crossbeam-channel](https://github.com/crossbeam-rs/crossbeam) for non-blocking, multi-producer single-consumer (MPSC) live sync and event looping.
- **Datetime Engine**: [chrono](https://github.com/chronotope/chrono) for handling timezone-aware parsing (UTC+8 Manila), chronotype day boundary shifts, and calendar layouts.
- **Serialization**: [serde](https://github.com/serde-rs/serde) and `serde_json` for parsing local JSON metadata (todos, classroom assignments, git metrics).

---

## Vault Data Integration

The dashboard functions as a visual utility layer reading straight from the local filesystem under the `~/smon-os/` vault. Rather than utilizing a traditional database or remote cloud integrations, it connects directly via:

- **Metadata Parsing**: Reads frontmatter and markdown tables from course organization files to dynamically locate grading structures and limits.
- **Log Aggregators**: Scans tracking files (JSON/CSV) generated by local sync engines for deadlines, sleep logs, and task details.
- **Incremental Scans**: Utilizes standard filesystem lookups to pull updates periodically.

---

## How the Dashboard Leverages SMON OS Data

The dashboard runs a background thread that periodically scans files in your vault to construct a unified view:

- **Streak Engine**: Reads git commits and your `todos.md` file. It applies a **04:00 AM chronotype day boundary** (so late-night coding counts toward the previous day) and cross-references `NoClassDays.md` to ensure official holidays never break your streak or consume your weekly freeze (`❄`).
- **Conflict Tracking**: Parses the `ExamSeasons.md` academic tables and cross-references them against `RecruitmentCycle-2026-27.md` from the COSS org folders. If an exam is within $\pm 2$ days of an org commitment, a conflict warning is triggered.
- **Live Sync Channel**: Uses a non-blocking `crossbeam-channel` event loop to periodically re-scan the vault files in the background, updating your dashboard without interrupting navigation or freezing the terminal.

## TUI Layout & Features

### Header Status
- Shows Manila local time, active streak count, best record, and weekly freeze (`❄`) usage.

### Main View (Swappable Tabs)
- **Tab 1: 18-Week Grid**: A comprehensive grid showing week-by-week performance (Git commits, completed todos, and graded milestones) across the semester. Inactive weeks are dimmed automatically.
- **Tab 2: Month Calendar**: An interactive calendar grid displaying class blocks expanded from `schedule.ics`. Days with overlapping exam and org commitments are marked with a bright red conflict warning (`[!]`). Selecting a date opens the **Day Detail Panel**, displaying an hourly timeline of classes, exams, org activities, and pending deadlines.

### Live Sidebar
- **Attendance Gauge**: Compares your lecture and lab absences against the 20% drop limit rules parsed directly from course syllabi.
- **Deadlines**: Displays the next 5 pending Google Classroom assignments, color-coded by urgency.
- **Sleep Log**: Shows your last 3 recorded nights from `sleep-log.csv`, calculating sleep durations (with cross-midnight support) and color-coding results by duration health.

## Controls

| Key | Action |
|---|---|
| `Tab` | Toggle between **Week Grid** and **Month Calendar** views |
| `Left` / `Right` | Move date selection back/forward by one day (Calendar view) |
| `Up` / `Down` | Move date selection back/forward by one week (Calendar view) |
| `q` | Exit the dashboard |

## Running the Dashboard

To run the dashboard locally pointing to your SMON OS vault:

```bash
# Run in development mode
cargo run -- --vault-path ~/smon-os

# Build the release binary
cargo build --release

# Run the installed binary system-wide
academic-dashboard --vault-path ~/smon-os
```
